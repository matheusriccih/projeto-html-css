# Página de Apresentação em HTML e CSS

Projeto de estudo de uma landing page responsiva criada com HTML e CSS puros. O objetivo foi praticar a construção de uma interface completa sem frameworks.

**Demo:** [matheusriccih.github.io/projeto-html-css](https://matheusriccih.github.io/projeto-html-css/)

## O que foi praticado

- Estrutura semântica com header, navegação, main, seções e footer
- Layout com Flexbox e CSS Grid
- Tipografia fluida e espaçamentos responsivos
- Navegação interna e links externos seguros
- Ajustes de layout para dispositivos móveis

## Como visualizar

Acesse a demo acima ou abra o arquivo `index.html` em um navegador. O projeto não possui dependências.

## Tecnologias

HTML5 e CSS3.
